# Rule-Based Jump Rope Routing Counter

This subproject contains the zone-aware rule-based jump rope counter.

Run the counter through:

```text
scripts/count_video_people.py
```

Zone definitions are stored in `config/`, and the reusable counting implementation is in `posecount/`.

For input requirements, commands, output fields, and troubleshooting, see:

```text
../../jump_rope/ROUTING_ALGORITHM.md
```
